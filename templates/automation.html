How it works

Every {{ interval }} seconds the scheduler polls the inbox for new (unseen) emails. Each new inquiry is run through the full pipeline:

  • Extract travel request (name, email, pax, destinations, budget...)
  • Generate itinerary + costing
  • Save records (requests / itineraries / costings)
  • Create a CRM lead
  • Auto-reply to the customer with the quotation
  • Send an internal alert email + WhatsApp alert

Already-processed email UIDs are tracked so nothing is double-processed.
